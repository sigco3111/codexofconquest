게임 소개

주사위를 공개적으로 굴리는 MUD

MUD MUD (Multi-User Dungeon)는 그래픽 이전 시대에 사람들이 터미널로 플레이하던 텍스트 게임입니다. 방은 하나의 문단이고, 이동은 나침반 방향이며, 세계는 그려지는 대신 글로 묘사됩니다.

Codex of Conquest는 바로 그런 게임입니다 — 주사위를 보여주면서. 방을 읽고, 동사를 고르고, 어딘가로 걸어갑니다. 불확실한 일이 생기면 게임은 d20 을 굴려 그 합산 전부를 보여줍니다 — 주사위, 수정치, DC, 결과까지 — 테이블에서 게임을 진행하는 사람이 소리 내어 말하듯이.

고전적인 테이블탑 규칙을 그대로 드러냅니다: 방어도(AC), 선공, 유리/불리, 내추럴 20 크리티컬, 무기별 피해 주사위, 여섯 가지 능력치. 그 어떤 것도 애니메이션 뒤에 숨기지 않습니다.

당신은 인간 파이터 챔피언 한 명을 플레이합니다. 레벨 1에서 20까지, 홀로 대륙을 가로지릅니다. 당신은 종종 남의 이야기에 고용된 용병입니다 — 그리고 게임은 그 점을 솔직하게 말합니다. 당신은 지휘하는 것보다 더 많이 목격합니다.

받기

세 가지 시작 방법, 설치 프로그램은 없음

게임 전체가 HTML 파일 하나입니다. 빌드할 것도, 가입할 계정도, 코드를 읽기 전에 감사할 의존성 트리도 없습니다.

지금 플레이

이 사이트에 있는 것이 최신 빌드입니다. 열기: play.html 을 열면 바로 시작됩니다. 세이브는 브라우저의 localStorage 에만 저장됩니다 — 업로드되는 것도, 외부로 연락하는 것도 없습니다.

파일 받기

약 5.5MB, 영원히 당신의 것:

# 게임만 — 오프라인으로 영구히 플레이 가능
curl -L -O https://raw.githubusercontent.com/sigco3111/codexofconquest/main/play.html
open play.html

# 또는 프로젝트 전체
curl -L https://github.com/sigco3111/codexofconquest/archive/refs/heads/main.zip -o codexofconquest.zip

태그된 빌드는 릴리스 페이지에 올라갑니다. 고를 산출물이 따로 없습니다 — 태그가 곧 파일입니다.

클론하고 도구 실행

git clone https://github.com/sigco3111/codexofconquest.git
cd codexofconquest
make install        # src/node_modules 복원
make                # 모든 타깃 나열
make play           # API + 모니터, 게임 열기
make edit           # 월드 에디터
make check          # 전체 게이트 체인
make test           # 960개 Playwright 테스트

node 프로젝트는 src/에 있습니다, 저장소 루트가 아니라 — src/NODE.md 에서 그 이유와 npm을 직접 실행하는 방법을 설명합니다.

🗝️시스템
시스템

파이터가 실제로 할 수 있는 모든 것

걷기, 보기, 싸우기, 나르기, 묻기, 견디기. 아래의 모든 시스템은 그 동사들을 중심으로 만들어졌습니다 — 검을 든 한 사람이 대륙에 가져올 수 있는 것의 전부이기 때문입니다.

🚶걷기

이동은 메뉴가 아니라 시스템입니다. 도로, 분기점, 항로가 있는 셀 그리드. 지형이 조우율을 결정하고, 거리는 시계에 맞서 날짜를 소모합니다.

🗺️월드 맵

네 개의 마을과 여덟 막에 걸친 416개 노드 — 비르카, 틸버리, 비스뷔, 바이마르 — 라이브 미니맵, 지역 뷰, 도로망을 따라가는 자동 이동을 갖췄습니다.

◆퀘스트

2,853개. 호위 비네트, 경유지 배달, 막을 가로지르는 장편 아크. 도착만으로 퀘스트가 완료되기도 합니다: 올바른 장소로 걸어가는 것이 곧 곧 동사입니다.

👹몬스터

티어 전반에 걸쳐 398종, 지형별 조우율 적용 — 준비되지 않은 곳으로 걸어가는 것이 치명적이 되기 전에 읽을 수 있습니다.

🎲기술 판정

STR, DEX, CON, INT, WIS, CHA — 그리고 행운(Luck). DC는 실행 전에 미리 알려주고, 실패는 보통 런 전체가 아니라 며칠의 시간만 앗아갑니다.

💬NPC와 호감

204개 프로필, 213개 대화 세트. 효율보다 사람을 택할 때 호감이 오르고, 엔딩은 당신이 지켜낸 친구들의 이름을 부릅니다.

🔖미션 비트

세계의 기억. 목격한 모든 사건이 비트를 세우고, 게이트·퀘스트·대화가 그것을 읽습니다. 세계는 당신이 한 일을 알고 있습니다.

🌑공허 압력

진짜 패배 조건. 수비가 얇은 곳에서 압력이 쌓입니다 — 스무 곳의 에픽 전장은 당신을 기다리는 구체적인 실패들입니다.

🪦죽음과 전리품

죽음은 시신과 되찾으러 걸어갈 수 있는 묘비를 남깁니다. 전리품 테이블, 무기 경제, 그리고 무엇을 잃었는지에 대한 정직한 안내.

🖋️문신

잉크로 새기는 성장 궤적. 특전, 배지, 표식은 당신이 채운 일지와 함께 뉴 게임+에서도 살아남습니다.

🌐메시 멀티플레이

선택 사항입니다. 로컬 서버를 실행하면 내 월드가 피어 메시에 합류합니다 — 위치 공개, 채팅, 합의 결투, 공유 지도, 해시 체인 장부.

📓일지

죽은 전령이 남긴 열일곱 개의 기록. 41번 항목은 페이지 중간에서 멈춥니다. 뉴 게임+에서는 당신이 42번 항목을 씁니다.

📓항목 42
스토리 레이어

페이지 중간에서 멈춘 일지

전령의 이름은 프로베르거였습니다. 그의 일지는 게임 초반에 발견되어 조각조각 읽힙니다 — 열일곱 개의 기록, 그중 다섯은 세계의 특정 장소에서 소리 내어 읽습니다. 41번 항목이 마지막입니다. 그는 페이지 중간에서 쓰기를 멈췄고, 그 아래의 빈 줄은 우연이 아닙니다.

주제는 바로 지식의 저주입니다: 무언가를 이해하고 나면, 그것을 몰랐을 때가 어땠는지 더는 기억할 수 없습니다. 프로베르거는 공허를 선명하게 보았고 사람들에게 말하려 했습니다. 그들은 들을 수 없었습니다. 그래서 그는 말하기를 멈추고 고치기 시작했고, 해야 할 일을 할 수 있는 유일한 사람이 되었습니다 — 그리고 그를 파괴한 것은 이빨을 가진 무언가가 아니라 바로 그 사실이었습니다.

뉴 게임+에서는 당신이 42번 항목을 씁니다. 엔딩은 네 가지입니다. 하나는 당신이 도운 모든 사람의 이름을 하나하나 부릅니다. 하나는 그렇지 않습니다.

🛠️빌드
세계 만들기

에디터가 함께 딸려옵니다

edit.html 은 비주얼 월드 빌더입니다 — 노드, 지형, 몬스터, 퀘스트, NPC, 그리고 미션 비트 — 게임이 이미 일어난 일을 아는 데 쓰는 플래그까지. 로컬 API에 연결하면 마을을 추가하고, 길을 잇고, 퀘스트 체인을 써서 실행 중인 게임에 나타나는 것을 볼 수 있습니다.

이후 CI 게이트 모음이 세계의 끊긴 링크, 도달 불가능한 노드, 중복 키, 절대 완료할 수 없는 퀘스트를 검사합니다 — 도달할 수 없는 콘텐츠가 이 프로젝트가 계속 발견해온 실패 모드이기 때문입니다.

115편의 기록, 모두 계측됨

이 프로젝트는 유난할 정도로 스스로를 문서화합니다. 중요한 작업마다 엔지니어링 기록이 있습니다: 명세, 실제로 출시된 것, 그리고 출시되지 않은 모든 것을 이름 붙이는 델타 표.

처음 기여하기 좋은 것들

  • 퀘스트 아크 쓰기. 형식은 문서화되어 있고 에디터는 비주얼합니다 — 엔진을 건드릴 일이 없습니다.
  • 지역 추가하기. 노드, 지형, 도로는 데이터입니다. 맵 솔버가 배치합니다.
  • 밸런스 잡기. 몬스터 티어, 드롭률, XP 곡선은 모두 표입니다.
  • 백로그 한 줄 가져가기. 진행 중인 작업은 6개 단계 백로그에 있고, 각 줄에는 근거와 반증용 grep이 적혀 있습니다.
